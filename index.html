FreeOS Any

名前の「Any」は「どこでも」の意味です。

WindowsもLinuxも使わず、USBメモリからPCで直接起動する小さな自作OSです（Intel・AMD と ARM の両対応）。
このページは紹介とダウンロード用で、いまのところOSはブラウザ上では動きません。画面は仮想PC（QEMU）で撮影したものです。

USB用ファイル (zip)仮想マシン用イメージ (img.gz)

いつものOSの上で動かす

macOSやWindowsを起動したまま、窓の中でFreeOS Anyを動かせます。仮想化ソフトQEMU（未導入なら起動時に案内）を使います。

Mac版 1.3 (dmg)

Windows版は後回しです（旧版 1.2、マウス非対応）。

  • dmgを開き、FreeOS Any を Applications にドラッグして起動する
  • Appleの署名がないため、止められたら「システム設定」→「プライバシーとセキュリティ」→「このまま開く」
  • QEMUがなければ画面の案内でインストール（先にHomebrewが必要）

Mac版はマウスとキーボードで操作できます。macOSの実機では未確認です。

単独のOSとして起動する／対応状況

  • Windows PC（Intel / AMD）、Windows PC（ARM）、Intel Mac: USBから直接起動
  • Appleシリコン Mac（M1以降）: 仮想マシンのみ（上のMac版など。直接起動は不可）

どのCPUでも実機での動作は未確認です。仮想PCでは x86-64 と ARM64 の起動を確認しています。

できること（1.2）

スタートメニュー、ターミナル、エディター、ブラウザ（文章とリンク）、ファイル転送、ソリティアなど。ブラウザとファイル転送には有線LANが必要です。

起動方法

  1. FAT32のUSBメモリを用意する（別の起動用USBには上書きしない）
  2. zipを展開し、EFIフォルダをUSBメモリの一番上にコピーする
  3. Windows PCは起動メニュー（F12やF11など、機種による）、Intel MacはOptionキーを押しながら電源を入れてUSBメモリを選ぶ

署名がないため、セキュアブートを無効にする必要があります。BitLocker（デバイスの暗号化）が有効なPCは、先に回復キーを控えてください。T2チップ搭載のIntel Macは起動セキュリティの設定変更も必要です。自己責任でお試しください。

操作

Esc スタートメニュー ／ F5〜F9 ターミナル・ファイル・エディター・ブラウザ・ファイル転送
F1 切替 ／ F4 閉じる ／ F10 最大化
電源オフ: スタートメニューの「シャットダウン」
Mac: Fキーは fn と一緒に。新しいメモはターミナルで edit 名前.txt

ファイル転送の通信は暗号化されません。信頼できるLANで使い、終わったら停止してください。
